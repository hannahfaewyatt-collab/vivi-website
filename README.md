# Vivi Website

The Vivi website project.

## Open in Claude Code

From an Ubuntu terminal, type:

```
Vivi
```

This runs `cd ~/vivi && claude --dangerously-skip-permissions` (the shortcut is defined in `~/.bashrc`).

## Link in bio (`/links`)

`links/index.html` is a free, MySpace-style link-in-bio page for Instagram.
Edit the `LINKS` list near the bottom of the file and paste in real URLs (buttons with an empty `url` are hidden).
Once the site is hosted, use `https://<your-domain>/links/` as the Instagram bio link.
